
# Battery Monitoring System

Arduino-based embedded system for real-time battery voltage and temperature monitoring.

## Features

* Real-time voltage monitoring
* Temperature tracking
* Alert mechanism for abnormal conditions
* Embedded sensor interfacing

## Components Used

* Arduino UNO
* Temperature Sensor
* Voltage Sensor
* LCD Display

## Technologies Used

* Arduino IDE
* Embedded C
* Sensor Interfacing

## Applications

* EV battery monitoring
* Battery health analysis
* Embedded monitoring systems
